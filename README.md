# PicoCar Racing

Created by [UPSIDE DOWN VR](https://upsidedownvr.cz/projekty).

PicoCar Racing is a free, proprietary arcade racing game by UPSIDE DOWN VR. The source code is not available. The Linux build attached to the Releases may be downloaded and redistributed unmodified; it may not be modified, decompiled or sold. See [LICENSE.txt](LICENSE.txt) for the full terms.

The game has been available as a free Linux download on the UPSIDE DOWN VR website since 2023. This repository hosts the Linux build and the packaging files used by the Flathub package.
